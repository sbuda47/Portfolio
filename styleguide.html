Design Tokens

The portfolio uses a shared token file for color, spacing, and typography values. These variables drive the CSS and help keep the site consistent.

{
  "colors": {
    "background": "#1E1E1D",
    "text": "#E7E7D6",
    "accent": "#FF8C00"
  },
  "type": {
    "fontFamilyBase": "Poppins, system-ui, sans-serif",
    "fontFamilyHeadline": "Black Ops One, Oswald, sans-serif",
    "fontSizeBase": "1rem"
  },
  "space": {
    "md": "1.5rem",
    "lg": "2rem"
  }
}
