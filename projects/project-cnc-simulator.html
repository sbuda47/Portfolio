CNC Simulator & G-code Visualizer

A personal Python lexer, parser and toolpath visualizer for RS-274 G-code. I use it as a first-pass sanity check before running code on a machine, helping me spot mistakes and reduce the chance of tool crashes or part failures.

Why I built it

I built this for myself to visualise the G-code I was writing, make learning easier and check whether the toolpath matched what I intended. The lexer, parser, machine-state tracking and other features grew from that need.

The tool is built for personal and small-batch use, serving as a first-pass sanity check for G-code validation. It's intentionally scoped for the engineering workflow I use, not as a production safety validator.

What it catches

  • Malformed or mistyped commands, flagged at the exact line
  • Out-of-sequence or invalid modal state
  • Visual mismatch between intended and actual toolpath
