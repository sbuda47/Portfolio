CNC Simulator & G-code Visualizer

Desktop tool to parse, simulate, and visualize RS-274/G-code toolpaths before running on hardware.

What it does

Parses G-code, maintains machine modal state, and renders the resulting toolpath with animation and diagnostics to catch unsafe or malformed commands.

My Role

  • Lexer, parser, and simulator implementation in Python
  • Tkinter GUI with Matplotlib 3D/2D visualizer and diagnostics
  • Test coverage for core parsing and simulation features

Tech

Python, Tkinter, Matplotlib, unittest

Notes

Supports linear moves, arcs, canned cycles, subprograms, and unit handling. Useful as a pre-run safety check.
