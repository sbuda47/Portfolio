What it is

MD-HI is a multivariate health index that measures how machine sensor values move together, rather than treating each signal separately. By combining Mahalanobis distance with EWMA smoothing and per-load calibration, the system delivers stable fault detection for conveyors and rotating equipment, even as operating conditions shift.

The approach

Motor and conveyor faults rarely announce themselves as a single bad reading — they appear as a change in correlation across many sensor channels. I reimplemented the MATLAB Mahalanobis-distance reference in Python, then added EWMA smoothing and load-aware thresholding so the health index stays stable across different machine loads.

Once the core pipeline was validated, I built the UART streaming layer to relay live index values and alarms to embedded controllers on the line, making the system suitable for real-time condition monitoring.
