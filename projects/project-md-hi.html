What it is

MD-HI is a multivariate health index that measures how machine sensor values move together, rather than treating each signal separately. It combines Mahalanobis distance with EWMA smoothing and per-load calibration, designed to reduce noise-driven alerts and account for changes in operating load.

The approach

Motor and conveyor faults can change the relationship between sensor readings. I used MATLAB to model and test MD-HI before building it for the actual system. I then rebuilt MD-HI in Python, using EWMA smoothing and load-aware thresholding to account for noise and different machine loads.

After checking the Python output against my MATLAB model, I built UART streaming tools to send health-index values and alarms to embedded controllers.

My role

  • Modelled and tested MD-HI in MATLAB, then rebuilt it in Python and checked that the numerical outputs matched
  • Designed EWMA smoothing and per-load calibration to reduce false positives
  • Built streaming tools for UART delivery to embedded controllers
  • Prepared validation figures and documentation for journal submission

Outcome

  • Per-load thresholding is designed to reduce false positives across loads
  • Streaming pipeline feeds embedded alarms directly to controllers
  • Validation figures and documentation prepared for journal submission
